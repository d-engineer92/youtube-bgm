# APIデータの保存期限・削除・利用境界

> 文書ID：POL-001  
> 状態：初回実装用の提案仕様（未実装）  
> 読む場面：API由来データを保存・表示・出力・復元するとき  
> 整理日：2026-10-14  
> 元資料：[初回実装仕様 v2](../archive/codex_research_first_mvp_v2.md) L208–L221。見出し・参照リンクを整理し、要件の内容は引き継いでいる。

競合の統計は通常、チャンネル所有者の認可を得ていないデータ。公式ポリシーでは、特例がない非認可統計を30日を超えて保持しないことが明記されている。[W2](../references/sources.md#w2)

初期提案は、観測点を28日間のローリング保存とし、現行情報は更新すること。これは30日ルールに余裕を持たせる実装上の選択であり、28日が公式の基準という意味ではない。

**最新値を取得し直しても、古い観測点の取得日を書き換えて保存期限を延ばさない。** 競合の長期時系列分析は、追加許諾の条件を確認してから別対応とする。

ローカル停止後は、閲覧・集計より前に期限切れデータを削除または除外し、削除処理を実行する。ログ、キャッシュ、DBバックアップ、API由来の数値を転記した文章にも不要な長期コピーを残さない。

利用者自身の企画文章はAPIキャッシュと分ける。ただしAPIデータやその派生物を「手書きメモ」という名前に変えただけで保存制限から外す実装にはしない。

独自分析・分類や外部AI利用の適法・適合性を一律に断定しない。API由来の分類・独自評価等は初回の実装対象外とし、必要なら公式の確認・監査手順で解決する。[W1](../references/sources.md#w1)[W2](../references/sources.md#w2)
