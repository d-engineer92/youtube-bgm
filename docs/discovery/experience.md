# 利用体験・結果の読み方

> 文書ID：EXP-002\
> 状態：EXP-A・EXP-B実装済み／2026-10-14。[検証記録](verification.md)。\
> 読む場面：画面Aと探索結果のUI、ブラウザー確認。

## 1. 最初に見る入口

既存の「探す・追う」を改修し、最上部に以下を置く。別の大規模ダッシュボードは作らない。

```text
どんなBGMを作るか、まだ決まっていなくても大丈夫です。
用途・雰囲気・音楽の方向を横断して、候補を探します。

調査プリセット：英語圏を想定（US / en）［変更：日本 JP / ja］
調べる範囲：8テーマ、最近30日、20分超の動画
標準計画：16検索ページ／最大160検索ヒット（重複を含む）
※詳細取得・再試行は別途API呼び出しが必要です。

［英語圏のBGMを広く調べる］
［前回の結果を見る］
▼キーワード・URLを指定して探す（既存機能）
```

APIキー未設定なら、ライブ開始を止め、キーの設定方法と「架空データで操作を試す」を案内する。デモへの自動切替はしない。デモの開始にも語の入力を要求しない。

ワーカー停止・DB接続エラー・API制限を「需要なし」にしない。ワーカー未稼働なら開始画面または進捗に起動方法を表示する。通常起動手順でWebとワーカーが一緒に使える構成にする。

## 2. 収集中

テーマ/条件ごとの未処理・処理中・完了・一部失敗を表示する。画面を閉じてもサーバー側の受付済み処理を失わない。読み取りのポーリングで進捗を更新し、GETや再描画でAPI取得を起動しない。

二重クリックは同じ実行へ案内する。停止は次のAPI呼び出し境界で処理し、受付済みの結果を捨てない。停止後は「続きから再開」を出す。

## 3. 結果はテーマ別の入口

テーマは探索条件のグループであり、動画の真のジャンルを判定したラベルではない。最初はカタログ順で表示し、テーマを「儲かる順」「需要順」に並べない。

各テーマカード：

- 日本語の名前・何を確かめるための検索か・実行した検索語と日本語の意味。
- 「最近30日・再生数順」「最近30日・新着順」を混ぜずに表示。APIの元の検索順と取得時刻を保持し、最新公開値の表示・取得済みの並べ替えとは区別する。
- 条件別の検索ヒット数、有効な動画の件数、取得できた異なるチャンネル数、重複件数、追加ページの有無。動画とチャンネルを合算したrun_items件数を動画件数にしない。
- サムネイル・原題・チャンネル・公開日・尺・公開再生数・公開登録者数・取得日。欠損は「未取得」、ゼロと区別する。
- プレビューは検索順の先頭数本。全取得結果を開ける。低再生・大規模/小規模を自動除外しない。新着も無作為標本ではないと説明する。
- 「2〜6本を比較」「選んだ動画をウォッチ」「古い作品も調べる」「別の切り口を探す」。比較・ウォッチは既存機能を再利用する。

同じ動画が複数テーマで出ても、動画レコードは共通。「他のどの条件でも見つかったか」を参照でき、総件数では一度だけ数える。テーマ間の件数差を市場規模差に読み替えない。

タイトルの自動和訳は今回実装しない。原題を保持し、辞書の日本語説明と問いで理解を補助する。

## 4. 初心者向けの問いと次の操作

| 状態 | 案内 | 次の操作 |
|---|---|---|
| 初回収集だけ | これは最近公開された動画の現在値です。今の増え方はまだ分かりません。 | 自動追跡の次回予定を見る（お気に入りは任意） |
| 複数チャンネルが見つかった | 各チャンネルで同じ用途・見せ方か、違う点は何かを確認します。 | 2〜6本を比較 |
| 一つのチャンネルに偏った | 一つの成功例だけで用途全体の需要とは判断できません。 | 別の検索語・新着を見る |
| 最近の上位作だけ見た | 低い再生数の例や公開直後の作品もあります。経過日を確認します。 | 新着側を開く |
| 古い高再生動画がある | 累計が多いだけでは現在も再生されていると分かりません。 | その動画の追跡履歴を見る |
| 0件または少数 | この条件と取得範囲では候補が少ない状態です。需要ゼロではありません。 | 別語／期間拡大／尺条件変更 |
| API失敗・日次枠不足 | 収集ができていません。人気や需要の判定材料ではありません。 | 設定確認／続きから再開 |

比較目的の任意ひな形：「同じ探索条件で見つかった作品について、公開経過・サムネイル・伝える用途の違いを確かめる」。自動で確定保存せず、利用者が確認・編集できる。

## 5. 深掘り

「古い作品も調べる」は、同じ語で公開180日以上前〜5年前の累計再生数順を1ページ取得する。継続需要の確認済みラベルは付けない。条件は[収集仕様](collection.md)が正本。

「別の切り口を探す」は、同梱カタログと承認済み候補から日本語の意味付きで提示する。入力不要で選べるが、一覧を開いただけでは検索しない。候補の出どころと「需要未検証」を表示する。辞書外の候補の更新は[キーワード拡張](keyword-expansion.md)を参照。

## 6. 数値と地域の表示境界

`regionCode=US`は米国から視聴可能という検索条件、`relevanceLanguage=en`は英語関連性であり、米国の視聴者比率ではない。テーマの見出しも「米国で人気」ではなく「英語圏を想定した検索」とする。国別RPM・視聴者国別内訳は取得できないため「未確認」。設定だけで高単価になるという説明はしない。

公開再生数と、同じ動画の2観測間の差分だけを、実取得時刻・経過時間付きで表示する。観測停止期間の補完、累計/公開日数を現在のVPHとすること、変化する対象群の合計を需要成長率とすることは禁止。複数観測や母集団の扱いは[データ仕様](data-and-retention.md)に従う。

## 7. 操作性

PCで数値と説明が読める文字サイズを維持する。スマートフォンではテーマ・条件・次の操作を縦に並べ、横スクロール必須にしない。ボタンはキーボード操作可能とし、色だけで成否を示さない。外部リンクはYouTubeと分かる表示、原題・サムネイルを改変しない。過去の手動検索結果・比較目的へ戻れる。
