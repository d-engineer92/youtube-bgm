# DEC-005：新着を含め全登録動画を初回から自動追跡する

- 整理日：2026-10-16
- 状態：利用者指示に基づく改修方針。実装・通常DB消去は未実施。
- 正本：[TRK-001](../tracking/README.md)

## 背景

キーワード不要の探索は実装されたが、日次更新は手動ウォッチした対象に限られていた。初回0〜一桁再生の動画を取得しても、その後の増加を自動追跡しなければ分析材料にならない。

前の会話で新着削減・最低再生数による採否を提案したが、利用者は「新着を減らさず、蓄積してから分析する」と明示した。初期再生数で選別すれば、今後伸びる動画と伸びない動画の比較を始める前に対象を変えてしまう。

## 決定

新着取得と低再生の取得を維持し、全登録動画を初回から自動追跡する。現在値更新とは別に日次の実観測値を追記し、画面と最小出力で比較できるようにする。手動ウォッチは分析上のお気に入りであり、追跡の必要条件ではない。

改修の利用切替時に、旧調査データ・メモ・ウォッチ・候補・旧ジョブを消去し、新たに観測を始める。今回の明示承認を安全な一回限りの手順へ限定する。通常起動でDBを初期化しない。API消費台帳・migration等の基盤記録を保護し、外部API予算を巻き戻さない。

## トレードオフ

追跡対象は増えるが、IDバッチ取得・重複排除・追跡優先の予算配分で対応する。容量が不足したら新規探索側を一時停止し、低再生動画から黙って追跡を切らない。追跡の無期限継続と統計の保存期間は区別し、現行の28日ローリング制約を明示する。

今回のリセットは比較の開始方式を揃える判断であり、過去の欠測を埋めたり、公開時点からの履歴を作れたりする操作ではない。
