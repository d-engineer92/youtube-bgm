# DEC-004：検索語未定から始める探索を優先する

> 状態：EXP-A・EXP-B実装済み、実API未確認。[検証記録](../discovery/verification.md)。\
> 決定日：2026-10-14

## 背景

作業1は検索・比較の土台として実装されたが、検索語やURLを既に知る利用者を前提としていた。利用者はジャンル・用途を知らない状態から需要を調べたいと指摘した。また日本だけでなく英語圏を視野に入れたい一方、費用と初期開発量は抑えたい。

## 決定

[探索入口EXP-001](../discovery/README.md)を次の作業として優先する。既存画面Aをおまかせ探索と手動検索の入口にし、US/enを初期プリセット、説明を日本語にする。JP/jaへの任意切替を用意するが、地域別アプリやDBを作らない。

8テーマの語をシステムが供給し、最近の再生数上位と新着を別に探索する。古い作品と別の語は結果から深掘りできる。カタログ拡張は固定JSONを人が確認する方式で、取得結果の自動ジャンル分類・有料AI・推定RPMは追加しない。

## 優先順位と影響

既存の検索・比較・ウォッチ、PostgreSQL専用、LA-1/LA-2は維持する。制作指示書全体を実装する旧作業2と、分析結果DB取込LA-3は別依頼のまま。今回追加する画面は探索の案内・結果表示に限る。

## トレードオフ

辞書だけでは未知の流行を自動検知できない。ただし利用者が事前に英語の語を調べなくても始められ、収集結果から語を増やせる。取得範囲は検索に依存する非無作為標本で、件数や再生数を市場規模・成功確率に変換しない。初期候補の網羅性は実取得で見直す。
