# DEC-006：失敗の反復取得を抑え、新規取り込みの枠を守る

決定日：2026-10-18。利用者から、追跡失敗と呼出増加により新規取り込みまでできなくなる設計の見直しを依頼された。

通常DBで、非返却1本の反復取得と、その未充足予定を理由にした新規検索拒否を確認した。追跡優先という方針だけでは、異常な対象が新規取得を無期限に妨げる。

全取得動画の追跡を維持したまま、理由別の再確認間隔、追跡の用途別上限、新規・手動用の最低枠を導入する。期限到来の有無ではなく、現在実行可能な追跡と新規詳細取得が予算内で共存できるかで判断する。具体的な契約は[TRK-002](../tracking/storage-and-jobs.md#5-api予算と公平性)、受入・運転確認は[TRK-005](../tracking/implementation.md#2026-10-18非返却の反復取得と新規検索停止の修正)を正本とする。

トレードオフとして、非返却から復帰した対象の自動検知は最大約1日遅れ得る。上限に収まらない規模・障害時には一部の予定が未充足で残る。これを低再生による停止や予定の先送りで隠さず表示する。Googleの実割当や他アプリの消費はアプリ内台帳からは保証できない。総枠の引上げ・課金・別プロジェクトへの切替は行わない。
