# 画面B：並べて分析する

> 文書ID：FTR-002  
> 状態：初回実装用の提案仕様（未実装）  
> 読む場面：比較画面・観察入力・YouTubeへのリンクを作るとき  
> 整理日：2026-10-14  
> 元資料：[初回実装仕様 v2](../archive/codex_research_first_mvp_v2.md) L72–L85。見出し・参照リンクを整理し、要件の内容は引き継いでいる。

2〜6動画程度を並べ、サムネイル・タイトル・尺・公開日時・公開数値・取得時刻を同じ画面で見る。表示件数はUI上の目安で、分析上の正解ではない。

- 再生数の多い動画だけでなく、比較対象として少ない動画も選べる。
- 同一チャンネル内比較と、複数チャンネル間比較の目的を区別して記録する。
- 公開後の経過時間、尺、ライブ等の形式の違いを表示する。比較条件の差があるだけで誤りとはしないが、解釈の注意を表示する。
- 人気順・新着順・古い順は、対象が「取得済み範囲」である場合、その旨を常時明示する。
- 動画はYouTubeで開いて視聴できればよい。初回はプレイヤーを自作しない。
- コメントはYouTubeで人が確認し、利用場面・要望・不明点を自分の言葉でメモする。投稿者の個人情報やコメント全文を大量保存しない。
- 音楽のテンポ・楽器等は、実際に聴いて記入する観察欄。未試聴のURLやタイトルだけから音楽内容を補完しない。

「分析してみましょう」という空欄だけのUIは禁止。分析ガイドの説明付き質問を表示する。
