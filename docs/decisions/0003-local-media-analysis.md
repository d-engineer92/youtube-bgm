# DEC-003：素材を保持しないローカル分析の追加

> 状態：ユーザーの追加依頼を反映した設計判断。実装は別作業。  
> 決定日：2026-10-14

## 背景

利用者は、競合と自作素材をCodexの契約利用枠とローカル計測で分析し、結果のみ残したい。入力、プロンプト、出力形式を固定し、DLディレクトリを常に未処理・分析可能な素材だけにしたい。

## 決定

初回の検索・比較基盤は維持し、[ローカル分析仕様](../local-analysis/README.md)を独立した追加範囲とする。許諾未確認の競合ダウンロードは引き続き行わない。許諾済みローカル素材と条件を満たす単一URL取得の入口を用意する。

バッチが取得・計測・検証・結果確定・削除を担当し、スキルは固定手順と考察を担当する。結果を確定してから一時素材を削除する。原本とコピーを分離する。DB停止が素材の長期保持理由にならないよう、ファイル出力と後続取込を分離する。

## トレードオフ

保存容量と素材保持を抑えられる一方、削除した素材をそのまま再視聴・再計測できない。ハッシュと計測結果を残しても音源の復元はできない。再取得では同一バイト列にならない場合もある。

プロンプト・版を固定して比較しやすくするが、LLMの文章の完全再現は保証しない。Codexへ送る要約・許可済み画像は外部推論の入力であり、完全オフラインではない。

実装コード・スキルはまだ存在しない。最初はファイル出力まで完成させ、DB取込と追加解析は必要性を確認してから行う。
