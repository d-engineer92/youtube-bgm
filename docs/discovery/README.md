# キーワード不要の探索入口

> 文書ID：EXP-001\
> 状態：2026-10-14の追加依頼に基づく実装仕様。EXP-A・EXP-B実装済み。モック/デモと実API基本操作を検証済み。複数日観測は未確認。[検証記録](verification.md)。\
> 読む場面：検索入口の改修を開始するとき。\
> 確認したmain：`f85440c35ffe6c65f2d83caf49a32b27f89ceb86`

## 完成させる利用体験

**APIの初期設定後、キーワード・ジャンル・用途を一つも入力せずに開始し、結果と日本語の案内を見ながら比較・観測する対象を選べる。**

「検索例を増やす」「ジャンル選択を必須にする」だけでは未達。既存の検索・比較基盤の前に探索案内を足す。チャンネルを作る前の需要調査を支援するもので、需要・高RPM・成功を自動認定するものではない。

## 今回の採用方針

- 主ボタンは「英語圏のBGMを広く調べる」。初期プリセットは米国を想定した英語検索。管理画面・説明・検索語の意味は日本語。
- 日本向けプリセットへ任意に切り替えられる。両方を自動で同時実行せず、別の探索実行として保存する。チャンネルの公開言語や所在地は変更しない。
- 最初の検索条件は同梱カタログから作る。初回は8テーマ・各2条件。辞書は需要の正解でも動画のジャンル判定でもない。
- 最近の再生数上位と新着を別々に収集する。古い作品・別の言い回しは、結果を見てボタンで追加調査する。
- 新しい候補探しと、選んだ同じ動画の継続観測は分ける。観測値がない初日は「未観測」と表示する。
- 追加の有料AI APIは使わない。検索語候補の更新は、設定ファイルまたは人が確認した固定JSONの取込で可能にする。
- DB・キュー・テスト・CIはPostgreSQLのみ。素材DL・楽曲生成・ローカル音声分析の実行には接続しない。

## 今回の完成範囲

EXP-A：入口、カタログ、収集と進捗、テーマ別の結果、比較・ウォッチへの接続。\
EXP-B：古い作品・別キーワードの深掘り、候補JSONの検証・取込、重複・復旧・期限・ブラウザーテスト。

**A/Bは一つの検索入口改修の実装順。両方までを今回の完成条件とする。** プルリクエストを内部作業単位で分けてもよいが、カタログ表示だけ、APIバッチだけでユーザー向けの完成としない。旧「作業2：分析ガイドと制作指示書」の全面実装は、この依頼には含めない。
