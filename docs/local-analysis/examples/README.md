# 書式例について

`analysis-v1.example.json` はJSON Schema検証のための架空例です。数値・時刻は例示、ゼロのハッシュはダミーです。実音源の計測結果でも、削除やfinalizeの成功を示す証跡でもありません。実際の意味検証・ハッシュ照合を通すために使わないでください。

`request-local.example.json` は入力マニフェストの記入例です。ファイルパスは存在を確認したものではありません。許諾確認フラグはすべてfalseで、確認せず実行しないようにしています。実装時には型・未知キー・パス/URL・権利確認を検証し、入力Schemaも用意してください。
