# DEC-002：仕様はdocs配下で責務別に分割する

状態：今回のユーザー要望を反映した文書構成。  
記録日：2026-10-14

## 背景

一つの巨大な設計書ではなく、AIが必要な情報だけ参照できる文書構成を求められた。実装用の文書はdocs配下へ置く。

## 方針

ルートはREADME.mdとAGENTS.mdを入口とし、詳細をdocsへ置く。docs/README.mdに文書一覧と作業別の参照先を置く。一つの責務を一つの正本で管理する。旧v1・v2はarchiveへ原文保存し、現行の分割文書を実装で参照する。

## 影響と留意点

参照先が探せるように入口と関連リンクも更新する必要がある。ファイルを小さく分けること自体を目標にせず、関連する仕様が散らばりすぎないようにする。元文書の主張・数値を変更する作業と、文書を分割する作業は区別する。

詳細な更新方法の正本は[文書管理ルール](../development/documentation-rules.md)。
