# DEC-001：初回は競合調査・企画支援に限定する

状態：今回までのユーザー要望とv2の方針を記録。アプリは未実装。  
記録日：2026-10-14

## 背景

ユーザーは楽曲生成費用と開発量を、成果が不明な段階で増やしたくない。一方、競合分析は十分に行い、初めてのYouTube運営でも見る観点を理解できる仕組みを求めている。実装担当はCodex。

## 方針

v1の全体構想を一括実装せず、v2の「探す・追う」「並べて分析する」「制作指示書・振り返り」を初回の提案仕様とする。数値一覧と空欄だけにせず、説明付きの問いを持たせる。

初回の正本は[目的・初回実装の範囲](../project/mvp-scope.md)。具体的な対象外や完了条件は正本と[受入条件](../development/acceptance-criteria.md)に置き、この記録に複製しない。

## 影響

v1に記載がある制作パイプライン等は、将来検討の記録であって初回の実装承認ではない。追加時は必要性・費用・許諾を別途確認する。売上や収益化を設計書だけで保証しない。
