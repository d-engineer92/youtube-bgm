# Codexへの追加実装依頼・受入条件

> 文書ID：LMA-006  
> 状態：LA-1・LA-2実装済み・人工素材検証済み。実素材検証とLA-3は未実施。\
> 整理日：2026-10-14  
> 読む場面：今回の拡張を実装・レビューするとき。

## 1. 初回の到達点

少数の素材で、取得または原本コピー→ローカル計測→Codex考察→検証済みJSON/CSV/Markdown→一時素材削除まで通ること。まずDBや新しい画面なしで完成させる。

進行中の検索・比較基盤とは別PRで実装する。現在の作業ブランチへ無関係な変更を混在させない。追加指示がない限り、既存の初回作業を今回のスコープへ差し替えない。

## 2. 実装の順番

### LA-1：ローカル素材、計測、結果確定、削除

外部ネットワークなしの人工テスト素材と許諾済みローカル素材から作る。専用ルート、コピー、状態、ロック、期限、計測、JSON検証、出力、cleanupを実装する。最初に原本削除や結果消失の事故を防ぐ。

### LA-2：固定スキルとネットワーク取得

既存CLIのサブコマンドを使うスキルを作成。固定プロンプトからinsightsを出力し、finalizeへ渡す。yt-dlpは同じ入口への取得アダプターとして追加し、許諾・単一動画・リトライ・上限・一時領域を確認する。これで最初の一連の流れは完成。

### LA-3：必要になったらJSONのDB取込

LA-1/2の出力を実際に見て有用性を確認した後、[出力契約](output-contract.md)の小さな取込コマンドを追加する。最初から汎用ETL、分析ダッシュボード、ジョブ管理画面を作らない。

## 3. 技術とコマンドの契約

既存アプリはLaravel/PostgreSQLのまま。ローカル解析の補助CLIにはPythonを限定利用してよい。別のWebサーバーは不要。まずFFmpeg/ffprobeと標準ライブラリ、JSON Schema検証程度に絞り、librosa等は追加計測が必要になってから採用する。

`python scripts/local-analysis/main.py <subcommand>` を予定インターフェースとする。実装後に実際に動くコマンドへREADMEを更新する。サブコマンド案：

| コマンド | 責務 |
|---|---|
| doctor | ツール・設定・ルート・版を確認。未導入なら停止し、自動課金・自動権限昇格しない |
| submit | マニフェストを検証し、ジョブを登録 |
| download / stage-local | 許諾済みURLの取得、または原本の通常コピーとREADYへの公開 |
| prepare | READYを占有し、計測パックと証拠を作成 |
| validate | insightsまたはbundleの構造・意味・ハッシュを検証 |
| finalize | 検証・3形式出力・bundle確定・成功時cleanupを一続きで実施 |
| cleanup | 確定後の削除再試行、期限切れ素材の削除。dry-run対応 |
| status | ジョブ別の状態と削除漏れを表示 |
| recover | 状態・ディレクトリ・確定マーカーを照合し異常停止から復旧 |

finalizeの内部がcleanupを呼び、スキルは最後にstatusと必要時のcleanup再試行を行う。人が毎回手で削除する前提にしない。各コマンドは非ゼロ終了で失敗を示す。ラッパーがエラーを成功へ丸めない。

単一CLIと少数モジュールで足りる。汎用ワークフロー基盤、常駐Codexデーモン、並列エージェントは不要。依存はロックし、分析実行のたびに最新版へ自動更新しない。

## 4. 必須テスト

| ID | 確認内容 |
|---|---|
| LA-AC01 | DL途中、壊れた実体、空ファイル、音声なしはREADYへ入らない |
| LA-AC02 | 成功後downloads/work/tmpに対象素材がなく、3形式とbundleが残る |
| LA-AC03 | 原本のハッシュ・サイズが不変。原本の削除・移動が起きない |
| LA-AC04 | 別ジョブ、親参照、symlink/hardlink、ルート自身への削除が拒否される |
| LA-AC05 | JSON不正、証拠ID不存在、未確認画像所見、計測値改変ではfinalize失敗 |
| LA-AC06 | 結果保存失敗では成功時削除しない。cleanup失敗は分析を繰り返さず再試行 |
| LA-AC07 | 確定rename直前・直後、削除途中、状態更新直前で中断してもrecoverが復旧 |
| LA-AC08 | 2プロセスが同じREADYを同時にclaimできない。期限cleanupが稼働中処理と競合しない |
| LA-AC09 | 24時間等の設定TTLが再試行で延長されず、次回起動で期限処理が先に動く |
| LA-AC10 | 全無音・短尺・片チャンネル無音・10秒未満・途中デコード失敗を正しく区別 |
| LA-AC11 | NaN/Infinity、秒とLUの取り違え、範囲外区間、重複IDを拒否する |
| LA-AC12 | 同じ入力・計測版の数値再現性を許容差付きで確認。AI文面の完全一致は要求しない |
| LA-AC13 | CSVとレポートはJSONから生成され、数式注入・HTML/Markdownの危険な出力を扱う |
| LA-AC14 | 再起動・同じ依頼の再投入で無駄な再DL/再考察をしない。別設定の再分析は別run |
| LA-AC15 | Cookie、APIキー、元音源、画像、署名URL、実分析結果がGitへ入らない |
| LA-AC16 | 取得拒否、上限到達、承認不足で停止。有料APIや自動クレジット購入に切り替えない |
| LA-AC17 | 画像を送信しないaudioモードで一連が動く。未提供楽器・ジャンルを生成しない |
| LA-AC18 | DB未起動でも分析・結果保存・素材削除が完了する |
| LA-AC19 | DB取込を実装した場合、dry-run、同一結果skip、同一ID異内容拒否、transactionを確認 |

CIには人工素材を実行時に生成するテストを置き、実YouTube動画や会員限定資料をコミットしない。実ネットワーク確認は許諾済み素材で別途実施し、未実施なら明記する。

`.gitignore` に `/var/local-analysis/` を追加し、依存キャッシュと秘密ファイルも除外する。ignoreは既存追跡ファイルには効かないので、Gitの追跡対象一覧も検査する。生素材の通常バックアップを作らない。
